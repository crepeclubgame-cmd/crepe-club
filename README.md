# Mini-site Crêpe Club pour GitHub Pages

## Mise en ligne

1. Décompresser cette archive.
2. Sur GitHub, créer un dépôt public nommé crepe-club.
3. Avec Add file > Upload files, déposer le contenu de ce dossier à la racine du dépôt. index.html, privacy.html, style.css et assets doivent être directement dans le dépôt. Ajouter .nojekyll si le sélecteur masque les fichiers commençant par un point. Le site statique fonctionne aussi avec le traitement Pages par défaut.
4. Valider avec Commit changes sur la branche main.
5. Ouvrir Settings > Pages.
6. Dans Source, choisir Deploy from a branch.
7. Choisir main puis /(root), et Save.
8. Attendre le déploiement. Settings > Pages affiche ensuite le lien Visit site.

## Fichiers

- index.html — présentation du jeu et contact.
- privacy.html — politique de confidentialité du jeu Android.
- style.css — mise en page pour téléphone et ordinateur.
- assets — bannière, icône et capture de jeu.
- .nojekyll — désactive le traitement Jekyll.

Ce dossier est prêt à être rendu public. La clé de signature et les fichiers Android sont conservés dans les archives de diffusion distinctes.

## Après la sortie sur Google Play

Modifier la phrase « La sortie sur Google Play est en préparation. » dans index.html.
Ajouter un lien vers la fiche confirmée du jeu lorsque celle-ci est accessible au public.
La page de confidentialité décrit le fonctionnement de la version Android 1.0.0. La réviser si de la publicité, des achats ou des services de mesure d’audience sont ajoutés.
